# 3D Store — Frontend

React 19 + Vite single-page application for the 3D Store API.

```bash
cp .env.example .env
npm install
npm run dev      # http://127.0.0.1:5173
npm run lint
npm run build
```

Set `VITE_API_URL` to the backend origin. The UI supports Turkish, English and German translations in `public/locales/`.

See the [root README](../README.md) for the full-stack setup, architecture and API notes.
